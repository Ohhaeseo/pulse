# PULSE 마이페이지 재설계 스펙

**문서 버전:** v1.0
**작성일:** 2026-05-26
**작성자:** Product Manager (subagent)
**범위:** `src/features/mypage/MyPage.jsx` UI/UX 재설계
**연관 가이드:** `MD/design_guide.md`, `CLAUDE.md`

---

## 1. 마이페이지 목적 재정의

마이페이지는 사장님이 PULSE 서비스와 맺고 있는 **관계 상태**를 한 곳에서 확인하고 관리하는 공간입니다. 구체적으로는 세 가지 관리 축을 담당합니다. (1) 내 가게 AI 프로필이 올바르게 설정되어 있는지 확인·수정, (2) 연동된 외부 플랫폼의 상태를 점검하고 누락된 채널을 추가, (3) 이용 중인 멤버십·크레딧 현황 파악 및 플랜 관리.

마이페이지는 **대시보드(가게 현황)의 보조 공간**으로 기능합니다. 인사이트나 행동 유도 지표(마케팅 준비 완료율 등)는 대시보드에서 소비하고, 마이페이지는 그 인사이트를 가능하게 하는 **설정·연동·계정 관리**에 집중합니다.

## 2. 신규 레이아웃 구조 제안

### 2.1 설계 원칙

- **Strong Box:** 최대 3개 (플랫폼 연동 카드 1 + 가게 AI 프로필 카드 1 + 멤버십 카드 1)
- **Soft Box:** 인라인 행(row) 요소에만 사용 (`bg-[#F5F7FA] rounded-xl`)
- **고객센터:** 멤버십 카드 하단 Divider 이후 인라인 링크 행 2개로 통합 (독립 카드 제거)
- **파란 배너 제거:** DashboardLayout 공통 Header가 담당하므로 내부 배너 불필요
- **섹션 구분 도구:** 섹션 제목 Typography + `gap-4` 여백 + 1px Divider. 배경 박스 추가 금지.
- **박스 중첩 금지:** 플랫폼 연동 카드 내부의 개별 플랫폼 행은 `border-b` Divider 또는 약한 배경톤(`bg-[#F5F7FA]`)으로 구분. 아이콘 배경 원형(`bg-white shadow-sm`) 유지 가능하나 부모 Soft Box 안에 또 다른 박스 생성 금지.

### 2.3 그리드 명세

| 영역 | 컬럼 | 행 | Strong Box 여부 |
|---|---|---|---|
| 플랫폼 연동 관리 | col-span-1 | row-span-2 | Yes (Strong Box 1) |
| 가게 AI 프로필 | col-span-2 | row-span-1 | Yes (Strong Box 2) |
| 멤버십 & 크레딧 + 고객센터 통합 | col-span-2 | row-span-1 | Yes (Strong Box 3) |

전체 그리드: `grid-cols-3 grid-rows-2 gap-4`

**고객센터 통합 방식:** Strong Box 3(멤버십 카드) 하단에 `border-t border-gray-100` Divider 후 인라인 행 3개(1:1 문의하기 / 서비스 이용 가이드 / 로그아웃)로 배치. 독립 카드 없이 멤버십 카드 내부 하단 영역으로 흡수.

## 3. 제거/추가/변경 항목 확정 목록

### 제거 (Remove)

- **파란 인사말 배너 (`bg-[#002B7A] ... 박사장님, 안녕하세요!`):** DashboardLayout 공통 Header와 인사말·페이지 타이틀 중복. 모든 다른 페이지에 자체 배너 없음. 제거 후 빈 공간은 Strong Box 3가 `row-span-1` 전체를 활용하여 흡수.
- **마케팅 준비 완료율 지표 (85% 원형 표시):** 마이페이지의 목적과 무관한 진행률 지표. Dashboard V2 `V2KpiTile` 영역에 적합. 완전 제거.
- **`animate-pulse` 무한 루프 (Naver Place 상태 dot):** `CLAUDE.md` Hard Constraint "무한 루프 애니메이션 금지" 위반. 정적 녹색 dot(`bg-green-500`)으로 교체.
- **`💡` 이모지 아이콘 (연동 팁 섹션):** `CLAUDE.md` "emoji를 UI 아이콘으로 사용 금지" 위반. Lucide `Lightbulb` 아이콘으로 교체.
- **연동 팁 Soft Box (`bg-blue-50 rounded-xl border border-blue-100`):** 플랫폼 연동 카드(Strong Box) 내부에 또 다른 박스를 생성하여 중첩 발생. 박스 제거 후 `Lightbulb` 아이콘 + 인라인 텍스트로 대체.
- **고객센터 독립 Strong Box (`col-span-1 row-span-1`):** 버튼 2개만 포함하는 단순 링크 목록에 Strong Box 소비는 과도함. design_guide.md §7.3 "단순 텍스트는 박스 대신 타이포+여백+디바이더" 원칙 위반. Strong Box 3(멤버십) 하단 영역으로 통합.
- **`Settings` 아이콘 전용 버튼 (가게 AI 프로필 우측 상단):** 접근 가능한 이름(`aria-label`) 미적용. 텍스트 레이블 포함 버튼으로 교체(`수정하기 →`).

### 추가 (Add)

- **오렌지 CTA 버튼 "플랜 업그레이드":** `bg-[#FF5A36CC] text-white rounded-lg font-bold`. 멤버십 카드 내 현재 플랜 정보 우측 또는 하단에 배치. 사장님의 핵심 행동 유도 요소로 design_guide.md §2 Action Main 컬러 의도에 부합.
- **오렌지 CTA 버튼 "연동하기" (미연동 플랫폼):** 카카오 채널 미연동 행에 `border-dashed` 대신 명시적 CTA 버튼 배치. 연동 행의 ChevronRight를 오렌지 "연동하기" 텍스트 버튼으로 교체.
- **로그아웃 기능 구현:** `LogOut` 아이콘은 이미 import되어 있으나 핸들러 미구현. 멤버십 카드 하단 고객센터 통합 영역에 로그아웃 인라인 행 추가. 클릭 시 세션 초기화 + `/login` 리다이렉트.
- **`useReducedMotion()` 분기:** `animate-in fade-in slide-in-from-bottom-4 duration-500` entrance 애니메이션에 `prefers-reduced-motion` 분기 추가. `CLAUDE.md` "모든 motion에 useReducedMotion() 분기 필수" 준수.
- **`aria-label` 접근성 속성:** 아이콘 전용 버튼(설정, 각 플랫폼 행의 ChevronRight 등) 전체에 적용.
- **모바일 반응형 그리드:** `grid-cols-3`를 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3`으로 변경. 현재 `grid-cols-3` 고정은 모바일 화면에서 레이아웃 완전 붕괴 원인.

### 변경 (Change)

- **"내 가게 대표 손님" → "가게 AI 프로필":** 현재 섹션명은 실제 내용(브랜드 톤앤매너, 주력 메뉴 키워드, 가게 기본정보)과 불일치. "AI 프로필"이 사장님 입장에서 직관적이며 AI가 이 설정을 기반으로 분석한다는 맥락을 전달.
- **`Settings` 아이콘 버튼 → `수정하기 →` 텍스트 링크 버튼:** `aria-label` 부재 문제 해소 + 행동 명확성 향상. `text-[#002B7A] text-sm font-bold` 스타일.
- **Naver Place `animate-pulse` dot → 정적 `bg-green-500` dot:** 무한 루프 애니메이션 제거. 상태 텍스트("수집 중")가 이미 의미를 전달하므로 시각적 보조는 정적 dot으로 충분.
- **연동 팁 Soft Box → 인라인 텍스트:** `bg-blue-50` 박스 제거. `Lightbulb` Lucide 아이콘(14px, `text-[#002B7A]`) + `text-[11px] text-gray-500` 텍스트를 카드 하단 여백 영역에 인라인 배치.
- **고객센터 카드 (col-span-1 row-span-1) → 멤버십 카드 내 하단 통합 영역:** 독립 Strong Box 제거로 Strong Box 총 개수 4 → 3으로 감소. design_guide.md §7.3 화면당 Strong Box 2~3개 상한 준수.
- **`grid-cols-3 grid-rows-2` 전체 그리드 → 플랫폼(col-1, row-2) + 나머지(col-2, row-2) 2단 구조 유지, 단 모바일 반응형 추가:** 데스크탑 구조는 동일하게 유지하되 `sm:` 이하 중단점에서 단일 컬럼으로 전환.

## 4. 사용자 스토리

### Story 1 - 플랫폼 연동 상태 확인

As a 외식업 사장님,
I want to 마이페이지에서 내 가게와 연결된 모든 플랫폼(Instagram, Naver Place, 카카오 채널)의 현재 상태를 한 화면에서 확인하고 싶습니다,
so that 어떤 플랫폼이 정상 연동되어 있고 어떤 것을 추가로 연결해야 하는지 파악할 수 있습니다.

**Acceptance Criteria:**
1. 연동된 플랫폼은 정적 녹색 dot + "연동됨" 또는 "수집 중" 텍스트로 상태 표시 (무한 애니메이션 없음)
2. 미연동 플랫폼 행에는 오렌지 "연동하기" 텍스트 버튼이 표시되며 클릭 시 해당 연동 플로우로 이동
3. 플랫폼 연동 카드는 1440×900, 1280×800 해상도 모두에서 스크롤 없이 완전히 표시
4. 각 플랫폼 행의 인터랙티브 요소에 `aria-label` 적용
5. 세 개 플랫폼(Instagram, Naver Place, 카카오 채널) 모두 기본 노출
6. 연동 팁은 박스 없이 Lightbulb 아이콘 + 인라인 텍스트로 카드 하단에 표시

---

### Story 2 - 가게 AI 프로필 수정

As a 외식업 사장님,
I want to 내 가게의 브랜드 톤앤매너와 주력 메뉴 키워드가 올바르게 설정되어 있는지 확인하고 수정하고 싶습니다,
so that PULSE AI가 나의 가게 특성에 맞는 인플루언서 추천, 홍보 문구, 리뷰 분석을 제공할 수 있습니다.

**Acceptance Criteria:**
1. "가게 AI 프로필" 카드에 가게 이름/업종, 브랜드 톤앤매너 태그, 주력 메뉴 키워드가 모두 표시
2. "수정하기 →" 텍스트 버튼이 카드 우측 상단에 위치하며 클릭 시 AI 프로필 수정 화면(또는 모달)으로 이동
3. 섹션 제목은 "가게 AI 프로필" (기존 "내 가게 대표 손님" 대신)
4. 설정 아이콘 전용 버튼 없음 — 텍스트 레이블 있는 버튼으로만 행동 유도
5. 카드 내 박스 중첩 없음 (브랜드 태그와 키워드는 인라인 뱃지로 표현)

---

### Story 3 - 멤버십 및 크레딧 현황 확인

As a 외식업 사장님,
I want to 현재 이용 중인 플랜, 남은 AI 생성 횟수, 다음 결제일과 결제 수단을 한눈에 보고 싶습니다,
so that 서비스 이용 한도를 인지하고 필요 시 업그레이드 결정을 내릴 수 있습니다.

**Acceptance Criteria:**
1. 현재 플랜명(Pro Plan 등) 배지, AI 생성 횟수 진행 바, 다음 결제일, 결제 수단이 모두 표시
2. "플랜 업그레이드" 오렌지 CTA 버튼이 카드 내 하단 또는 플랜명 우측에 표시
3. 오렌지 CTA는 `bg-[#FF5A36CC]` 토큰 사용, 다른 버튼과 색상 혼용 없음
4. 진행 바(`bg-[#002B7A]`)가 실제 사용량 비율을 올바르게 반영
5. 결제 수단 정보는 마지막 4자리만 노출 (보안)

---

### Story 4 - 고객센터 접근 및 로그아웃

As a 외식업 사장님,
I want to 서비스 이용 중 문의가 생겼을 때 빠르게 고객센터에 연결하거나 서비스 가이드를 볼 수 있고, 필요 시 로그아웃하고 싶습니다,
so that 마이페이지 하나로 서비스 관련 모든 관리 행동을 완결할 수 있습니다.

**Acceptance Criteria:**
1. "1:1 문의하기", "서비스 이용 가이드", "로그아웃" 세 항목이 멤버십 카드 하단 Divider 이후 인라인 행으로 표시
2. 고객센터 전용 독립 카드 없음 — 멤버십 카드 내 통합 영역
3. 로그아웃 클릭 시 세션 초기화 후 `/login` 경로로 이동 (현재 미구현 상태 → 구현 필요)
4. 각 행에 Lucide 아이콘(MessageCircle, FileText, LogOut) + 텍스트 레이블 조합
5. 각 버튼에 `aria-label` 적용

---

### Story 5 - 모바일 환경에서 마이페이지 접근

As a 스마트폰으로 PULSE를 확인하는 외식업 사장님,
I want to 작은 화면에서도 마이페이지의 모든 카드를 깨지지 않게 볼 수 있고 싶습니다,
so that 이동 중에도 플랫폼 연동 상태와 멤버십 현황을 확인할 수 있습니다.

**Acceptance Criteria:**
1. `sm:` 미만 뷰포트에서 그리드가 `grid-cols-1` 단일 컬럼으로 전환
2. 모든 카드가 가로 스크롤 없이 완전히 표시
3. 오렌지 CTA 버튼이 모바일에서도 탭 가능한 크기(최소 44×44px touch target) 유지
4. 텍스트, 배지, 아이콘이 작은 화면에서 겹치거나 잘리지 않음
