# PULSE 적용 AI 기술 요약

중간발표 제출용 | 작품 적용 AI 관련 기술

## 요약

PULSE는 소상공인의 실제 리뷰 데이터를 분석해 고객 페르소나와 고객 여정지도를 만들고, 이를 홍보영상 제작까지 연결하는 AI 마케팅 운영 도구입니다. 핵심 흐름은 “리뷰 데이터 -> 고객 이해 -> 홍보 실행”입니다.

## 적용 기술

- BERTopic: 네이버·카카오 리뷰를 토픽별로 분류합니다. 오픈소스 사전학습 모델에 리뷰 데이터 기반 추가 파인튜닝/도메인 튜닝을 적용합니다.
- GPT-5: 리뷰 토픽과 원문 리뷰를 바탕으로 대표 고객 페르소나, 방문 목적, 불편점, 고객 여정지도를 구조화합니다.
- DSPy: 페르소나, 분위기, 품질 모드, 이미지, 메뉴 콘셉트를 고정 입력값으로 받아 Veo3용 프롬프트 기획안을 구성합니다.
- Veo3: DSPy와 LLM이 만든 기획안을 바탕으로 9:16 숏폼 홍보영상을 생성합니다.

## 처리 흐름

리뷰 수집 -> BERTopic 리뷰 분류 -> GPT-5 페르소나/여정 도출 -> DSPy 프롬프트 구조화 -> Veo3 숏폼 생성

## 효과

- 실제 리뷰 기반으로 홍보 타깃과 메시지를 정합니다.
- DSPy로 영상 프롬프트의 입력·출력 형식을 고정해 결과 흔들림을 줄입니다.
- Veo3로 촬영·편집 부담 없이 숏폼 홍보물 제작을 지원합니다.

## 개발 보조 활용

MCP와 Skill은 코드 탐색, 문서 변환, 브라우저 검증, 반복 작업 자동화에 보조적으로 활용했습니다. 작품의 핵심 AI 기능은 BERTopic, GPT-5, DSPy, Veo3 파이프라인에 두었습니다.
