## 1. 문제 인식 (Problem)

### 1-1. 창업 아이템의 배경 및 필요성

#### 외식업 마케팅의 구조적 한계

대한민국 외식업 소상공인은 약 **73만 개소**(2024 통계청)에 달하며, 전체 소상공인의 약 40%를 차지합니다. 이들 중 대다수는 **SNS 마케팅이 매출에 직접 영향을 미친다는 사실을 인지**하고 있으나, 실제로 지속적인 마케팅을 실행하는 비율은 **10% 미만**입니다.

이 괴리의 원인은 외식업 사장님이 직면한 **3대 구조적 장벽**에 있습니다.

| 장벽 | 구체적 현황 | 결과 |
|---|---|---|
| **지식의 장벽** | 고객 세그먼트·데이터 분석 역량 부재. "어떤 손님에게 어떤 콘텐츠를 보여줘야 하는지" 판단 불가 | 콘텐츠 방향 설정 실패 → 무의미한 게시물 양산 |
| **시간의 장벽** | 조리·서빙·정산·관리를 1인 또는 소수 인력으로 처리. 촬영·편집에 투입할 시간 0 | SNS 계정 방치 → 잠재 고객 유실 |
| **비용·신뢰의 장벽** | 배달앱 광고비 월 50~200만 원 부담. 마케팅 대행사 불투명한 요금 체계 | 외부 서비스 불신 → 자체 해결 시도 → 포기 |

#### 숏폼 콘텐츠 시장의 급성장

"릴스(Reels)"와 "쇼츠(Shorts)"로 대표되는 **숏폼 콘텐츠 시장은 연평균 25% 성장**(Statista 2024)하고 있으며, 외식업 마케팅에서 가장 높은 전환율을 보이는 채널로 부상했습니다.

그러나 **기획 → 촬영 → 편집 → 업로드**의 전 과정을 사장님 혼자 수행하기는 현실적으로 불가능합니다.

> **핵심 문제 정의:**
> 외식업 사장님은 "마케팅을 해야 한다"는 것을 알지만,
> 지식·시간·비용의 3중 장벽으로 인해 **"할 수 없는" 구조적 한계**에 놓여 있습니다.

#### 정부 정책 부합성

2026년 중소벤처기업부는 **'혁신 소상공인 AI 활용 지원사업'**을 신설하며, POS 시스템·회계 자동화·마케팅 자동화 등 AI/디지털 시스템 도입을 적극 지원하고 있습니다. PULSE는 이 정책의 핵심 대상인 **"AI 기반 마케팅 자동화"에 정확히 부합**하는 솔루션입니다.

## 2. 실현 가능성 (Solution)

### 2-1. 창업 아이템 현황 (준비 정도)

PULSE는 **아이디어 단계가 아닌, 작동하는 MVP를 보유**한 상태입니다.

| 구분 | 상태 | 기술 스택 | 상세 |
|---|---|---|---|
| **프론트엔드** | ✅ MVP 완성 | React(Vite), Tailwind CSS, Framer Motion | 대시보드·인사이트·영상생성 3대 화면 작동 |
| **메인 백엔드** | ✅ MVP 완성 | Spring Boot 3.x, JPA, MySQL | JWT·OAuth2 인증, RESTful API, FastAPI 연동 |
| **AI 백엔드** | ✅ MVP 완성 | FastAPI, BERTopic, MoviePy | NLP 분석 파이프라인, LLM 페르소나 생성, 영상 렌더링 |
| **크롤링 시스템** | ✅ 작동 | Playwright | 네이버 방문자리뷰 + 카카오맵 리뷰 이중 수집 |
| **사용자 검증** | 📋 예정 | - | 2026.06 사업 시작 후 외식업 5곳 PoC 파일럿 |

### 2-2. PULSE의 핵심 해결 방식 — 마케팅 자동화 루프

PULSE는 사장님의 마케팅 문제를 **3단계 자동화 루프**로 해결합니다.

```
[1단계: 손님 마음 읽기]  →  [2단계: 홍보 영상 만들기]  →  [3단계: 우리 가게 현황]
   (Understand)                (Create)                    (Evaluate & Action)
        ↑                                                         │
        └─────────────── 다음 행동 제안 ──────────────────────────┘
```

**1단계: 손님 마음 읽기 (Understand)**
- 네이버·카카오 리뷰를 **BERTopic으로 의미 분석** → 주요 토픽(맛, 가성비, 분위기 등) 도출
- **LLM이 고객 페르소나 자동 생성** — "퇴근길 직장인", "해장 손님" 등 직관적 타겟
- 플로팅 AI 채팅으로 궁금한 점 즉시 질문 가능

**2단계: 홍보 영상 만들기 (Create)**
- 타겟(페르소나)만 고르고 **사진을 업로드하면 끝**
- AI가 **Hook-Body-Outro 숏폼 문법**으로 스토리보드 자동 기획
- **MoviePy로 9:16 세로형 릴스 자동 생성** (6~10초, 자막·모션 포함)

**3단계: 우리 가게 현황 (Evaluate & Action)**
- 복잡한 그래프 대신 **"다음 행동" 1줄 제안** — "비 오는 날엔 배달 영상 추천!"
- **No Scroll Policy** — 한 화면에서 모든 정보 파악
- 제안 버튼 클릭 → 즉시 영상 제작 단계로 이동 (루프백)

### 2-3. 핵심 기술 및 차별화 포인트

| 기술 요소 | 구현 방식 | 차별점 |
|---|---|---|
| **이중 플랫폼 크롤링** | Playwright로 네이버+카카오맵 동시 수집 | 단일 플랫폼 대비 **데이터 완성도 2배** |
| **BERTopic 의미 분석** | Sentence-Transformers 임베딩 → HDBSCAN 클러스터링 | 단순 키워드 빈도가 아닌 **문맥 기반 토픽** 도출 |
| **LLM 페르소나** | GPT/Gemini 기반 구조화된 고객 유형 생성 | 특성·선호·목표·불편점 4축 페르소나 |
| **숏폼 자동 기획** | Hook-Body-Outro 문법 적용, 스토리보드 자동 생성 | 영상 전문가의 기획 프로세스를 **AI로 완전 자동화** |
| **행동 중심 대시보드** | Action-Centric UX, No Scroll Policy | "숫자"가 아닌 **"다음 행동"**을 보여주는 UX |

### 2-4. 경쟁 서비스 비교

| 비교 항목 | **PULSE** | 네이버 스마트플레이스 | 배달앱 광고 | 외주 마케팅 대행 |
|---|---|---|---|---|
| 마케팅 지식 필요 | ❌ 불필요 | ⚠️ 중간 | ⚠️ 중간 | ❌ 불필요 |
| 월 비용 | 💰 2.9만원 | 무료~💰 | 💰💰💰(50~200만) | 💰💰💰💰(100만+) |
| 콘텐츠 자동생성 | ✅ AI 자동 | ❌ | ❌ | ✅ 외주 |
| 데이터 기반 전략 | ✅ 리뷰+상권 NLP 분석 | ⚠️ 제한적 | ❌ | ⚠️ 제한적 |
| 실행까지 소요 시간 | **~5분** | 30분+ | 의존적 | 1주+ |

**PULSE의 핵심 차별점:** 기존 서비스는 마케팅의 "일부"만 해결하지만,
PULSE는 **분석 → 제작 → 평가의 전체 루프를 AI로 자동화**합니다.
