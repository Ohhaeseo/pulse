# 증빙서류-패키징

증빙서류를 제출 순서대로 안정적으로 정리하기 위한 skill입니다.

## 목표

- 필수/해당 시 자료를 구분합니다.
- `[붙임]` 체계를 유지합니다.
- 본문과 증빙의 역할을 분리합니다.

## 작업 절차

1. 공식 제출목록 양식에서 필수 항목과 해당 시 항목을 구분합니다.
2. 실제 제출 대상만 남기고 순서를 확정합니다.
3. `[붙임 1]`, `[붙임 7-1]` 같은 라벨을 유지합니다.
4. 상세 증빙은 본문이 아니라 별첨 2로 보내는 것이 유리한지 먼저 검토합니다.
5. 증빙용 `.docx`와 이미지 계획이 서로 일치하는지 확인합니다.

## 이 repo에서 우선 활용할 스크립트

- `business/build_appendix2_docx.py`

## 기본 제출 순서 예시

1. 신분증 사본
2. KCI 논문 등재 증빙
3. MVP 상세 화면
4. 기술 아키텍처
5. 사용자 흐름도

## 금지

- `[붙임]` 라벨 누락
- 본문/증빙 자료 간 중복과 충돌 방치
