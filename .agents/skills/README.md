# Canonical Skill Directory

이 저장소의 대표 skill 경로는 `./.agents/skills` 입니다.

## 운영 원칙

- 새 skill은 기본적으로 이 디렉토리에 추가합니다.
- 기존 `./.agent/skills`는 레거시 호환용으로 유지합니다.
- 기존 레거시 skill이 계속 필요하면 이 디렉토리로도 함께 반영해 통합 가시성을 유지합니다.

## 현재 통합 상태

- 새로 만든 예창패/문서/PNG/증빙 skill이 이 디렉토리에 있습니다.
- 기존 레거시 skill인 `doc-exporter`, `git-ops`도 이 디렉토리로 복사해 두었습니다.
