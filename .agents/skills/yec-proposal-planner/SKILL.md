# 예창패-사업계획서

2026 예비창업패키지 사업계획서와 제출 구조를 안정적으로 설계하기 위한 skill입니다.

## 목표

- 본문 10페이지 제약을 먼저 반영합니다.
- 본문과 별첨 2를 분리합니다.
- 섹션별 핵심 메시지를 짧고 심사위원 친화적으로 정리합니다.

## 우선 입력

- `business/[별첨 4] ... 주요 질의응답.pdf`
- `business/2026년 예비창업패키지 예비창업자 온라인 사업신청 매뉴얼.pdf`
- `business/2026년 예비창업패키지 예비창업자 증빙서류 제출목록 안내.docx`
- `business/[별첨 1] ... 사업계획서 양식.docx`

## 작업 절차

1. 공식 로컬 문서에서 제출 제약을 먼저 확인합니다.
2. 본문과 별첨 2에 들어갈 자료를 먼저 분리합니다.
3. 본문은 `문제-해결-수익화-팀` 중심으로 압축합니다.
4. 이미지는 먼저 `본문 필수 3개 이내` 원칙으로 정리합니다.
5. 나머지 증빙은 `[붙임]` 구조로 별첨에 배치합니다.

## 출력 형식

- 섹션별 개요
- 본문/별첨 분배안
- 이미지 삽입 계획
- 제출 전 체크리스트

## 금지

- 공식 근거 없이 첨부 가능 여부를 단정하지 않습니다.
- 본문 분량을 확인하지 않은 채 이미지를 마구 배치하지 않습니다.
